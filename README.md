🔐 IoT Door Lock System

Este repositorio contiene la implementación de un sistema de cerradura inteligente basado en tecnologías IoT, integrando control de hardware con comunicación mediante servidor.

📁 Estructura del Proyecto

Dentro de este repositorio se encuentra la carpeta principal:

IOT-door-lock/

En esta carpeta se organizan los diferentes componentes del sistema:

📂 src/
Contiene los archivos fuente del proyecto:
Código del servidor en PHP, encargado de la gestión de solicitudes y comunicación con el sistema.
Código de Arduino, responsable de la configuración del hardware y el control de la circuitería según los requerimientos del sistema.
🖼️ Diagrama del circuito (.png)
Imagen que muestra la implementación física del circuito, incluyendo todas las conexiones necesarias para el funcionamiento del sistema.
🎥 Video demostrativo

📄 Documento PDF
Archivo que contiene información adicional del proyecto, como descripción detallada, funcionamiento, consideraciones técnicas y posibles mejoras.
⚙️ Descripción General

El sistema IoT Door Lock permite el control de acceso mediante un microcontrolador (Arduino), el cual interactúa con un servidor para validar y gestionar las operaciones. Este enfoque combina hardware y software para lograr un sistema seguro y funcional.

🚀 Funcionalidades
Control de acceso basado en identificación.
Comunicación entre dispositivo físico y servidor.
Implementación de circuito electrónico funcional.
Monitoreo y validación mediante backend en PHP.
📌 Requisitos
Arduino (compatible con el código proporcionado)
Servidor web con soporte para PHP
Conexión a red (WiFi o local según configuración)
Componentes electrónicos según el diagrama proporcionado
